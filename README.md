# جدول الحصص الذكي — مدرسة المبادرة للبنات

<p align="center"><img src="logo.png" width="140" alt="شعار المدرسة"></p>

تطبيق ويب لتوزيع الحصص الأسبوعية تلقائياً على الشعب والمدرّسات بلا تعارض.

## المزايا
- التوزيع الذكي للتكليفات: يمنع تعارض المدرّسة والشعبة، ويحترم يوم الإجازة والحد اليومي.
- إدخال / تعديل يدوي مع تثبيت الحصص.
- الجدول العام، جدول كل شعبة، جدول كل مدرّسة، ونصاب المدرّسات.
- لوحة المديرة: تحديد عدد الصفوف والشعب ومدرّسات الملاك والعقود.
- لون خاص لكل مدرّسة في الجدول، ومنع أي تعارض في الحصص.
- تصدير إلى Excel (CSV) ونسخة احتياطية (JSON).

البيانات تُحفظ تلقائياً في متصفح الجهاز المستخدم.

تصميم: علي الصفار — الموصل، العراق
